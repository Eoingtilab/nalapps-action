# 날라액션 v1.0.0

날라액션의 첫 정식 안정 버전입니다.

## 주요 기능

- Windows 전역 마우스 이동, 클릭, 버튼, 휠 녹화
- 키보드 일반키 및 Ctrl/Alt/Shift/Win 조합키 녹화·재생
- 저장하지 않은 현재 액션 즉시 실행
- 녹화/실행 버튼 상태 전환 및 전역 긴급 중지 `Ctrl+Shift+F12`
- 단계 추가, 편집, 삭제, 활성/비활성, 위/아래 순서 변경
- 텍스트 입력 및 대기 시간 단계
- `.nlaction` 액션 저장/불러오기
- 손상되거나 허용되지 않은 액션 파일 fail-closed 검증
- 원자적 파일 저장 및 미저장 변경사항 경고
- 날라액션 자체 UI 조작은 녹화 대상에서 제외
- NALLA APPS 인트로 화면, 중앙 실행, 페이드 인/아웃
- 날라액션 전용 Windows 아이콘

## 지원 환경

- Windows 10/11 x64
- self-contained .NET 8 빌드이므로 일반 사용자 PC에 별도 .NET Runtime 설치 불필요

## 주의

관리자 권한으로 실행된 프로그램을 자동화하려면 날라액션도 동일한 권한 수준으로 실행해야 합니다. Windows 보안 화면, UAC Secure Desktop 등 OS가 입력 주입을 차단하는 영역은 자동화 대상에서 제외됩니다.
